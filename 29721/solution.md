## Info

[변형 체스 놀이 : 다바바](https://acmicpc.net/problem/29721)

- 난이도: 실버 4
- 분류: 구현

---

## 💡 풀이 방법 요약

- 핵심 아이디어 정리

1. 체스판의 크기 n, 다바바의 개수 k를 한 줄로 입력받음(map 사용)
2. 두번쨰 줄부터 k+1줄까지 다바바(기물)의 위치 입력받음(기물이 여러 개니까 for문, set집합 활용)
3. 기물의 위치와 방문한 위치를 구별해서 구현
4. 상하좌우 총 4번 이동 가능하므로 for문 활용해서 경우의 수 구함

---

## 👀 실패 이유

- 처음엔 모든 경우의 수를 구하는 문제라는 것만 보고 dfs 사용하려고 함. 근데 한번만 이동한다는 조건에서 탈락
- 여러 개의 기물을 차례대로 움직이는 문제라고 생각해서 실패
- 기물의 위치랑 방문한 위치를 각각 2차원 배열로 구현했는데 시간 초과로 실패
- 시간을 줄이기 위해 입력을 sys.stdin.readline으로 받고, 기물 위치를 set()으로 모으고, 방문 위치만 2차원 배열로 구현했는데 시간 초과로 실패(시간 초과뿐만 아니라 2차원 배열 시작 좌표와 if 범위 설정에서도 틀림)
- 기물 위치랑 방문 위치 둘 다 set으로 변경, 체스판 좌표가 (1, 1)부터 (n, n)임을 생각해 if 범위 수정

---

## 🙂 마무리

- 문제를 제대로 이해하는 데에 시간이 많이 걸린 것 같음. 문제에 주어진 조건을 꼼꼼하게 확인하는 습관 필요함.
- for문이나 if문 구현할 때 범위 꼭 제대로 생각해야 함.
- 유연하게 구현 방법을 바꿀 수 있도록 공부를 많이 해야할 것 같음 ㅠ(ex. 2차원 배열만 고집하지 말고 set 같은 집합을 사용하는 등...)
